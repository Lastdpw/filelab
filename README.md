# FileLab — студенттің файл шеберханасы

GitHub Pages үшін толық браузерлік нұсқа. JPG, PNG және PDF беттерін тексеріп, бұрып, реттеп, LMS шегіне сай PDF дайындайды. **Файлдар серверге жүктелмейді:** Python, Pillow, NumPy, pypdf және ReportLab браузердегі WebAssembly worker ішінде орындалады. PDF көрінісін Mozilla PDF.js жасайды.

## Қолдану

Сайтты ашып, өңдеу модулінің жүктелуін күтіңіз. Алғашқы жүктеуде шамамен 23 МБ қолданба ресурстары керек; барлық кітапхана осы репозиторийден жүктеледі, CDN-ге тәуелділік жоқ. **Демо беттер** немесе **Файл қосу** арқылы бастаңыз. Беттерді тышқанмен сүйреп немесе ↑/↓ арқылы реттеңіз. Сенсорлық экранда ↑/↓ батырмаларын пайдаланыңыз.

**Тапсыру шегі** әдепкіде 10 МБ. Бөлшек мәнді үтірмен немесе нүктемен жазуға болады (`2,5` немесе `2.5`). 1 МБ = 1 000 000 байт. Үш PDF нақты жасалады; шекке сыятын ең жоғары сапа ұсынылады. `1, 3-5` сияқты аралықтар, JPG/PNG экспорты, бетті ауыстыру, сапаны және бағытты тексеру бар. Жоғары сапада бастапқы PDF мәтіні сақталады; сығылған режимдер беттерді суретке айналдырады.

Сессия осы қойындының жадында ғана сақталады. **Тазарту**, қойындыны жабу немесе бетті жаңарту жүктелген беттерді жояды. Браузерлік нұсқа сервердегі cookie-сессияларды қолданбайды. Файлдарға арналған желілік POST сұрауы жоқ. Сайт ресурстарының кәдімгі GET сұрауларын GitHub Pages қабылдайды.

Бір файлға шамамен 67,1 МБ, бастапқы файлдар жиынына 100,7 МБ, 40 бет, суретке 24 мегапиксель шегі қойылған. PDF көріністерінің қосымша шегі — шамамен 201,3 МБ. Құпиясөзді PDF қабылданбайды. Қате файл бұрын қосылған беттерді өшірмейді.

## Модель және тексеру

`orientation_model.npz` және `documents.py` бастапқы FileLab жобасынан өзгеріссіз алынған. JPG және PNG үшін жүйе жарықты теңестіріп, төрт бағыттағы KNN дауыстарын біріктіреді. Бағыт анық болмаса, бетті қолмен бұруға болады. `browser_core.py` бастапқы веб-сессия логикасын браузерге бейімдейді; PDFium орнына PDF.js жасаған растр қолданылады. Модель қайта оқытылған жоқ.

Деректер `train.py` арқылы жасанды түрде жасалған. 150 бастапқы оқу беті → 600 бұрылған сурет; бөлек 48 бастапқы тест беті → 192 сурет. Бөлу бұрмай тұрып жасалады; тестте басқа бастапқы нөмірлер, мәтін тобы және үлгілер бар. 0°, 90°, 180°, 270° санаттары қолданылады; KNN — 9 көрші. Дауыс 65%-дан аз немесе күңгірт аймақ 1,7%-дан аз болса, қолмен тексеру белгісі қойылады.

Браузердегі Pyodide ортасында 192 тест суреті қайта өлшенді: **144 дұрыс, 75%**. Бұл нақты телефон суреттерінің дәлдігі емес. Нәтиже `browser-verification.json` ішінде.

| Нақты / болжам | 0° | 90° | 180° | 270° |
| --- | ---: | ---: | ---: | ---: |
| 0° | 36 | 0 | 12 | 0 |
| 90° | 0 | 36 | 0 | 12 |
| 180° | 12 | 0 | 36 | 0 |
| 270° | 0 | 12 | 0 | 36 |

Үш демо: `01-upright.png` 0° → 0°; `02-sideways.png` 90° → 270° түзету; `03-upside-down.png` 180° → 180° түзету. `04-blurry.png` бұлыңғыр деп белгіленеді. Мәтінсіз `test_diagram-1003-0` сызбасында нақты 0° орнына 180° (44,6% дауыс) болжанған: шеңбер симметриясы шатастырады, бет қолмен тексеруге қалады.

Браузерлік функционалдық тексеру: демо, бағыт, бұлыңғыр белгі, өшіру/реттеу, үш PDF көлемі, үш бетті қайта қосу, `4, 6` аралығы, JPG/PNG, мәтіні бар PDF, бүлінген файл, 41 бет, еш нұсқа сыймайтын шек және сессияны тазарту — өтті. Экспортталған мәтін: `FILELAB SELECTABLE TEXT`.

Үш демо беттің 03 → 01 → 02 ретімен нақты көлемдері:

| Режим | Байт | 0,24 МБ |
| --- | ---: | --- |
| Жоғары сапа | 305 183 | Асады |
| Орташа | 219 012 | Сыяды, ұсынылады |
| Шағын файл | 170 701 | Сыяды |

Браузер мен Windows нұсқаларының Pillow/JPEG ортасы әртүрлі болғандықтан, байт көлемдері аздап өзгеше. Әр интерфейс нақты өзі жасаған файлдың көлемін көрсетеді.

## Жергілікті іске қосу және тексеруді қайталау

Осы бумадан `python -m http.server 8766 --bind 127.0.0.1` орындап, `http://127.0.0.1:8766/` ашыңыз. Бұл тек статикалық файлдарды таратады; өңдеуге Python сервері пайдаланылмайды. `file://` арқылы ашу Web Worker шектеулеріне байланысты қолдау таппайды.

`browser-tests.zip` архивін осы буманың ішіне ашып, `/qa.html` бетіндегі **Тексеруді бастау** түймесін басыңыз. Тест бетінде PDF операциялары және 192 жасанды сурет өлшенеді. Бұл тек синтетикалық материалдар; жүктелген пайдаланушы файлдары архивте жоқ.

`FileLab-Web.zip` — бастапқы Windows/Python веб-нұсқасы. Оның ішінде толық `train.py`, desktop қолданбасы, тәуелділік нұсқалары, `TEAM.md`, деректердің сипаттамасы және тексеру командалары бар.

## Нұсқалар және шектеулер

Pyodide 0.28.3 (Python 3.13), NumPy 2.2.5, Pillow 11.3.0, pypdf 6.10.0, ReportLab 4.4.9, charset-normalizer 3.4.4, PDF.js 5.4.296. `runtime-versions.json` нақты тізімді береді. Тарату шарттары LICENSE файлдарында және wheel архивтеріндегі `.dist-info` бумаларында сақталған.

Соңғы Chromium/Firefox/Safari және WebAssembly қолдайтын браузер керек. Үлкен PDF әлсіз телефонда баяу болуы немесе жад шегіне жетуі мүмкін. Тікелей сыртқы сілтеме ресурстары бар күрделі PDF, сирек CJK қаріптері және PDF формалары толық тексерілмеген. OCR, перспектива түзету және еркін бұрышпен туралау жоқ. Браузерлік нұсқа ашық қойындыда интернетсіз файл өңдей алады; офлайн алғашқы ашылу кепілденбейді.

## Нақты жұмыс журналы

GitHub Pages үшін WebAssembly бейімдеу, PDF.js көрінісі, браузердегі сессия, жергілікті кітапханалар жинағы, PDF/сурет экспортын тексеру, 192 суретті қайта өлшеу және жариялау дайындығы. Студенттер атынан жеке үлес жазылған жоқ. Модель дәлдігі жаңа нақты деректерге телінбейді.
