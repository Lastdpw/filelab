# FileLab

FileLab — тапсырма фотоларын реттеп, өңдеп, бір PDF файлға жинайтын қазақша веб-қолданба. JPG, JPEG, PNG және PDF файлдарын қабылдайды. Барлық өңдеу браузерде жүреді.

**[FileLab сайтын ашу](https://lastdpw.github.io/filelab/)** · [Браузерлік тексеру нәтижесі](browser-verification.json)

## Қолдану

1. **«Файл қосу»** батырмасымен құжаттарды таңдаңыз. Сайтты бірден сынау үшін **«Демо беттер»** батырмасын басыңыз.
2. Беттерді тізімде реттеңіз. Бетті ауыстыруға, өшіруге, оңға немесе солға 90° бұруға болады.
3. Қажет болса, JPG немесе PNG бетіне **«Ақ-қара»** не **«Құжат сканы»** сүзгісін қолданыңыз. Жарықтық, контраст және айқындық әр фотоға бөлек реттеледі.
4. PDF-ке кіретін беттерді таңдаңыз. Мысалы, `1, 3-5` мәні 1, 3, 4 және 5-беттерді қосады. Өріс бос болса, барлық бет экспортталады.
5. Ұсынылған сапаны таңдаңыз да, **«PDF жүктеу»** батырмасын басыңыз. Таңдалған бетті JPG немесе PNG ретінде бөлек сақтауға да болады.

Қырынан немесе төңкеріліп тұрған суреттің бағыты автоматты түрде тексеріледі. **«Қолмен тексеріңіз»** белгісі шықса, көріністі қарап, қажет болса бұрыңыз. **«Бастапқы»** және **«Түзетілген»** батырмалары өңдеу нәтижесін салыстыруға көмектеседі. Сайт қараңғы немесе бөлшегі аз суреттерді де белгілейді.

## PDF сапасы мен көлемі

FileLab үш нұсқаны құрастырып, әрқайсының нақты көлемін көрсетеді. **Әдепкі тапсыру шегі — 10 МБ**, яғни 10 000 000 байт. Шекке сыятын нұсқалардың ішінен сапасы ең жоғарысы ұсынылады. Шекті өзгертуге болады, мысалы `2,5` немесе `2.5` МБ. Үш нұсқа да шектен асса, сайт ескерту көрсетеді.

| Режим | Суреттің ұзын жағының шегі | JPEG сапасы |
| --- | ---: | ---: |
| Жоғары сапа | 2400 пиксель | 94 |
| Орташа | 1550 пиксель | 82 |
| Шағын файл | 1050 пиксель | 66 |

Бастапқы PDF-тегі таңдалатын мәтін **«Жоғары сапа»** режимінде сақталады. Орташа және шағын режимдер PDF беттерін сурет ретінде сақтайды. Фотоны PDF-ке салғанда оның жазуы суреттің бөлігі болып қалады.

## Бағыт моделі

[Бағыт модулі](orientation.py) суретті 171 сандық белгімен сипаттайды. KNN сол белгілерді [сақталған үлгілермен](orientation_model.npz) салыстырып, ең жақын **9 үлгінің** салмақталған дауысы арқылы **0°, 90°, 180° немесе 270°** бұрышын болжайды. Фотолар үшін жүйе жарықты теңестіріп, төрт қалыптағы нәтижелерді біріктіреді. Болжам жеткілікті анық болса, сайт бетті кері бұрышқа бұрады.

Оқу жинағы **150 жасанды беттің 600 бұрылған нұсқасынан** тұрады. Бөлек 48 беттен дайындалған **192 жасанды сынақ суретінің 144-і** негізгі KNN арқылы дұрыс жіктелді. **75% — осы жинақтағы дәлдік.** Телефон фотолары үшін бөлек дәлдік көрсеткіші өлшенген жоқ.

| Нақты бұрыш / болжам | 0° | 90° | 180° | 270° |
| --- | ---: | ---: | ---: | ---: |
| 0° | **36** | 0 | 12 | 0 |
| 90° | 0 | **36** | 0 | 12 |
| 180° | 12 | 0 | **36** | 0 |
| 270° | 0 | 12 | 0 | **36** |

Қырынан және төңкеріліп тұрған үлгілерді **«Демо беттер»** арқылы сынауға болады. Дәптер торы, көлеңке және симметриялы сызбалар болжамды қиындатуы мүмкін.

## Қалай жұмыс істейді

| Файл | Міндеті |
| --- | --- |
| [index.html](index.html), [style.css](style.css), [app.js](app.js) | Қазақша интерфейс, беттер тізімі және өңдеу құралдары |
| [engine.js](engine.js), [worker.js](worker.js) | PDF.js арқылы алдын ала көрініс жасау және Pyodide ортасында өңдеуді іске қосу |
| [browser_core.py](browser_core.py) | Сессия, бағытты тексеру, фото сүзгілері және көлемдерді салыстыру |
| [documents.py](documents.py) | Суретті тексеру, JPG/PNG сақтау және ReportLab пен pypdf арқылы PDF құрастыру |

Pillow суреттерді өңдейді, NumPy пиксельдер мен модель белгілерін есептейді. Python коды Pyodide арқылы браузердегі Web Worker ішінде жұмыс істейді. Кітапханалар GitHub Pages арқылы осы репозиторийден жүктеледі. Нұсқалары [runtime-versions.json](runtime-versions.json) файлында берілген.

Жүктелген беттер ашық қойындының жадында сақталады. Бетті жаңартпас немесе қойындыны жаппас бұрын дайын файлды жүктеп алыңыз. Бір сессияға **40 бетке дейін** қосуға болады. Бір файлға шамамен **67,1 МБ**, барлық бастапқы файлға **100,7 МБ**, әр суретке **24 мегапиксель** шегі бар. Құпиясөзбен қорғалған PDF қабылданбайды.

## Жергілікті іске қосу

Репозиторийді жүктеп, оның бумасында мына команданы орындаңыз:

```bash
python -m http.server 8766 --bind 127.0.0.1
```

Браузерде [http://127.0.0.1:8766/](http://127.0.0.1:8766/) мекенжайын ашыңыз. Бұл команда сайт файлдарын жергілікті түрде таратады. Фото мен PDF өңдеу браузерде орындалады.

Браузерлік сынақты қайталау үшін [browser-tests.zip](browser-tests.zip) архивін репозиторий бумасына ашып, `/qa.html` бетіне өтіңіз. Бастапқы Windows/Python нұсқасы және оқу деректерін дайындайтын `train.py` файлы [FileLab-Web.zip](FileLab-Web.zip) архивінде бар.
